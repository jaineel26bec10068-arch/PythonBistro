# Python Bistro

A menu-driven restaurant ordering and billing system built entirely in Python.

## Features
- Customer name and order type
- Dine-In / Takeaway
- 10-item menu
- Multiple items and quantities
- Current order view
- Automatic subtotal
- 5% GST
- Final bill
- Input validation
- Automated tests

## Run
`python main.py`

## Test
`python test_bistro.py`

No Flask, HTML, JavaScript, database, JSON, or local storage is used.
