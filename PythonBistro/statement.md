# Project Statement - Python Bistro

## Problem Statement
A restaurant needs a simple system to record customer orders, calculate item costs, apply GST, and generate an accurate bill.

## Objectives
- Accept customer and order-type information.
- Display a predefined menu.
- Record multiple items and quantities.
- Calculate subtotal and 5% GST.
- Generate a final bill.
- Validate invalid input.
- Demonstrate modular Python programming and testing.

## Functional Modules
1. Customer and order-type management
2. Menu display and ordering
3. Current-order management
4. Billing and GST calculation
5. Input validation and error handling

## Non-Functional Requirements
- Clear command-line interface
- Reliable input validation
- Modular and maintainable code
- Independently testable calculations

## Scope
This is a command-line prototype. It uses in-memory data only and has no database, web interface, online payment, or persistent storage.
